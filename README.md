# Ferramenta-de-teste-requisitos-ddos
Esta ferramenta foi desenvolvida exclusivamente para testes de carga, desempenho e estabilidade em sites, servidores e sistemas que pertençam ao usuário ou para os quais ele possua autorização expressa para realizar testes.

# 🔐 Autorização

Antes de utilizar a ferramenta, certifique-se de que você possui autorização para testar o sistema ou infraestrutura escolhida. Testar sistemas de terceiros sem permissão pode violar leis, contratos, políticas de provedores e termos de serviço.

# 🚫 Uso indevido

Não utilize esta ferramenta para:

- Derrubar ou tentar indisponibilizar sites ou servidores de terceiros;
- Realizar ataques DDoS ou DoS;
- Sobrecarregar intencionalmente uma infraestrutura sem autorização;
- Interromper serviços de outras pessoas ou empresas;
- Contornar mecanismos de segurança, limites ou proteções;
- Realizar qualquer atividade maliciosa ou não autorizada.

# ✅ Uso permitido

A ferramenta pode ser utilizada para fins legítimos, como:

- Testar seu próprio site;
- Avaliar a capacidade de um servidor sob carga controlada;
- Identificar problemas de desempenho;
- Realizar testes em ambientes de desenvolvimento ou laboratório;
- Aprender sobre redes, programação e testes de desempenho;
- Realizar avaliações de segurança com autorização.

# 📌 Responsabilidade

O usuário é inteiramente responsável pela utilização da ferramenta e deve garantir que seus testes estejam dentro dos limites autorizados e sejam realizados de maneira controlada.

Os desenvolvedores deste projeto não incentivam, apoiam ou se responsabilizam por qualquer uso ilegal, abusivo ou não autorizado da ferramenta.

## Use com responsabilidade. Teste apenas aquilo que você tem permissão para testar. 🔐💻
